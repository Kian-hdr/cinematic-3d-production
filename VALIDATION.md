# Validation scope

Release 1.1.0, 27 October 2026, is a documentation workflow update. It adds portable viewport-first timing, continuous capture, temporal review and cost/evidence guidance. No private project policy, media, editor, runtime, credentials or machine-specific paths are bundled.

Release checks: skill frontmatter validation, YAML metadata inspection, local Markdown target resolution, version/setup alignment, complete tracked-payload review and private-path/credential-shape heuristics. Final release notes identify the source commit, ZIP and SHA-256; download bytes are compared with the local package. These are package checks rather than a proof that every assistant follows the guidance.

Scenario review covers three boundaries: a compressed rig test does not prove final pacing; an upscaled output is not described as native internal rendering; and a screenshot/contact sheet does not establish full moving visual/audio review. Native simulator/engineering evidence remains separate from cinematic work.

No Blender/Unreal rendering, GPU benchmark, cloud operation, assistant behavior evaluation, visual acceptance or performance savings are established by this release. Capture options are candidates to measure against the installed engine and actual hardware.
